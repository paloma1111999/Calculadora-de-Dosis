# Rat Anesthesia Dosage Calculator

A simple and interactive Python script designed to calculate and verify anesthesia dosage requirements (Ketamine and Xylazine) for laboratory rats based on their body weight.

---

## What It Does

* **Dynamic Calculation:** Automatically computes the required volume of Ketamine and Xylazine in milliliters.
* **Continuous Workflow:** Features an interactive loop allowing users to calculate dosages for multiple subjects sequentially without restarting the program.
* **Safety Reminder:** Includes a built-in safety prompt to ensure careful handling during administration.

---

## How to Use

1. Ensure you have **Python** installed on your system.
2. Download or copy the script (`main.py`) into your local environment.
3. Run the script from your terminal or command line:
```bash
python main.py

```


4. Follow the on-screen prompts:
* Enter the subject's weight in grams when requested (`Ingrese el peso en gramos`).
* Review the calculated doses for Ketamine (ml) and Xylazine (ml).
* Choose whether to calculate another dose (`1` to continue, `0` to exit).
